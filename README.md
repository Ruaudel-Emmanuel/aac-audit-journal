## 🎯 Mission

L'AAC applique le protocole **4 phases** à chaque session :

| Phase | Nom | Rôle |
|---|---|---|
| **A** | Issue Audit | Vision stratégique — suggérer des issues orientées futur et robustesse |
| **B** | Code Review | Analyse technique — architecture, sécurité, performance |
| **C** | PR Assessment | Évaluation de maturité — le code est-il prêt à merger ? |
| **D** | Synthèse | Conclusion positive et prochaine étape concrète |
